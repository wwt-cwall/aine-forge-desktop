# Support

Thank you for using Aine Forge Desktop! We're here to help you get the most out of this project.

## Getting Help

If you need assistance, have questions, or want to report an issue, there are several ways to get support:

### 🐛 Report a Bug or Issue

If you've found a bug or encountered an issue, please report it on our Issues page:

**[Report an Issue](https://github.com/wwt-cwall/aine-forge-desktop/issues)**

When reporting an issue, please include:
- A clear description of the problem
- Steps to reproduce the issue
- Expected vs. actual behavior
- Your environment (OS, version, etc.)

### 💬 Join the Discussion

Have questions, ideas, or want to discuss the project? Join our community discussions:

**[GitHub Discussions](https://github.com/wwt-cwall/aine-forge-desktop/discussions)**

This is a great place to:
- Ask questions about usage
- Share ideas and feature requests
- Connect with other users and contributors
- Get help from the community

### 📫 Contact

For other inquiries, you can reach out through:

- **GitHub Profile**: [@wwt-cwall](https://github.com/wwt-cwall)
- **Repository**: [aine-forge-desktop](https://github.com/wwt-cwall/aine-forge-desktop)

## Contributing

Interested in contributing to the project? We welcome contributions! Please check out:

- **[Issues](https://github.com/wwt-cwall/aine-forge-desktop/issues)** - Find issues to work on or report new ones
- **[Discussions](https://github.com/wwt-cwall/aine-forge-desktop/discussions)** - Discuss ideas and proposals

## Response Time

Please note that this is an open-source project maintained by volunteers. We'll do our best to respond to issues and questions in a timely manner, but response times may vary.
